Extreme Honeymoons: Site Color Scheme

This color scheme was created with the Paletton Color Scheme Designer using a teal base color (057D6D) with its orange complement. Paletton's export page was unavailable, so this page displays the exported color values directly. The teal reflects water, ice, and mountain adventures while the warm sand and orange tones reflect the red rock desert of southern Utah.
