Web Site Critiques

Questions:

  1. What was your first impression of this site?
  2. How does this site organize the flow of information? (Do they have links on the left and text on the right? Some other scheme? No scheme?)
  3. Does the site structure make sense or does it confuse you? Why?
  4. Does the site graphics/layout/multimedia enhance the site or detract from it? Why?
  5. How long did it take for the home page to load? Was the load time reasonable?
  6. Was the text color and size readable? If a background color or image was used, did it enhance or detract from the site?
  7. Did the site have a navigation bar or other navigation tool? Was the navigation well done?
  8. Did the site have a color scheme or look and feel that was repeated on all the pages?
  9. How does the site respond to smaller window sizes (responsive design)?
  10. What does this site offer that was unusual or very well done?

Website Critique - Jami Lin

www.jamilin.com

  1. My first impression of this site is that it looks very busy and dated, and there is just too much going on.
  2. This site does not seem to have a specific way of organizing information. There are links all over the page, and if there is a scheme, it seems to change frequently throughout the site.
  3. The site's structure is very confusing. It is unclear what the website's purpose actually is, and there is a large amount of information crammed onto each page.
  4. The graphics, layout, and multimedia really detract from this site. Each page is overwhelming, and most of the graphics are not even relevant to the text they sit next to.
  5. The home page took a few seconds to load, which I think is a reasonable load time.
  6. The text color was readable, but I think the font should have been a bit bigger. There was no background color on the home page, which I think enhanced the site.
  7. The main navigation tool on this site appears to be a link to a sitemap, which is hard to use and poorly done in my opinion.
  8. This site does not have a consistent color scheme that carries across all of its pages.
  9. This site does not have a responsive design. When I made the browser window smaller, I had to scroll sideways to read the content.
  10. What was unusual about this site is the sheer number of topics it covers, most of which seem completely unrelated to each other.
